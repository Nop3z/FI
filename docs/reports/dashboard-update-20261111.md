## 一、更新了什么

### 1. 版式：16:9 桌面优先
- 宽屏（≥1101px）下左右双栏：左栏 = 状态汇总表 + 实时明细日志流，右栏 = 三张 delay 分布图；主面板高度锁定为一屏（`calc(100vh−110px)`），明细表**内部滚动**，不再把整页拉成 3000px 长条
- 明细表固定渲染**最新 30 条**（增量插入，新纪录置顶）
- 窄窗口（≤1100px）自动退化为上下堆叠，行为与旧版一致

### 2. 样式全面对齐 ViewViewView（VVV）原版精确值
| 项 | 现值 | 来源 |
|---|---|---|
| SUCCESS 柱 / 表格数字绿 | `#19ff25` | VVV `--vvv-count` / `--vvv-number` |
| HANG 柱 | `#e05252` | VVV `.vvv-stat-fill--hang` |
| UNEXPECTED 柱 | `#4d33ff` | VVV `.vvv-stat-fill--custom` |
| 表格行距 | th `6px 10px` / td `4px 10px` | VVV `.vvv-th` / `.vvv-td` |
| 表格列宽 | 紧贴内容（`max-content`），不拉伸满宽 | VVV `.vvv-table` |
| X 轴标签 | 垂直排（自下而上阅读）+ 84px 固定标签区 | VVV `.vvv-stat-lab` |

### 3. 分布图升级
- X 轴刻度改为**区间标签**，如 `3135-3140`。技术侧需要知道的一个决策：`/api/histogram` 目前是**逐 raw 计数**（无桶边界字段），前端在展示层按 `[lo, lo+5)` 聚合（计数=区间内原生桶求和，无伪造、无单位换算），图表下方轴注已声明"桶宽 5 raw · 区间含左不含右"
- SUCCESS 与 HANG 图上下各占半列，UNEXPECTED 通高图贴底填满，柱子随窗口高度自动拉伸

### 4. 细节修正
- 全页数字去千分位（`6,114` → `6114`）
- 汇总表 count 列与明细表 delay·raw 列垂直对齐（右缘误差 <1px，自动重算）
- 删除明细区头部条（标题/筛选按钮/条数下拉）——筛选与条数改由 URL 参数配置（见下），页面保持只读、无控制按钮

### 5. AI 可配置化（重点）
- 所有可调字段集中到 `window.FI_CONFIG`（带逐字段中文注释），启动时控制台打印 `[FI] effective config`
- 支持 URL 参数覆盖，非法值自动回落默认、不报错

## 二、前端面板怎么用

### 启动与访问
```bash
cd <PROJECT_ROOT>/dashboard
python app.py            # 端口 8765；或双击 start.cmd（推荐，可常驻）
```
- **真实模式**：`http://127.0.0.1:8765`
- **演示模式**：`http://127.0.0.1:8765/?demo=1`（不连后端，底部有橙色横幅"后端未连接 · 当前为演示数据"，演示数据绝不冒充实测；后端不可达时真实模式也会自动降级进演示并显示同一横幅）

### 页面结构
| 区域 | 内容 |
|---|---|
| 顶栏 | 标题 + 语义标注（unconfirmed-v0.1）+ ns 假设标注 + 手动刷新按钮 |
| 左栏 | state|count 汇总表（状态原始字面量透传）；下方实时明细日志流（最新置顶，内部滚动） |
| 右栏 | 三张 delay 分布图，悬停任意柱显示 `区间 · 计数/总数 · 百分比` |
| 面板下方 | 「AI 活动」「契约与单位假设」两个折叠区（契约版本动态解析） |
| 底部状态行 | 已记录总数 / 当前窗口 / 更新时间 / live 绿点 |

### URL 参数（AI 与自动化可以直接拼 URL 配置）
| 参数 | 取值 | 作用 | 示例 |
|---|---|---|---|
| `demo=1` | — | 演示模式 | `/?demo=1` |
| `state` | 状态字面量之一 | 预置筛选（只看该状态） | `/?state=<STATE>` |
| `limit` | 1–500 | 明细表窗口条数（默认 30） | `/?limit=50` |
| `bin` | 1–100 | 直方图区间宽 raw（默认 5） | `/?bin=10` |
| `poll_records` / `poll_activity` / `poll_histogram` | ≥500 | 轮询间隔 ms（默认 2000/3000/30000） | `/?poll_records=5000` |
| `color_success` / `color_hang` / `color_unexpected` | `#RRGGBB`（`#` 转义为 `%23`） | 覆盖柱色 | `/?color_hang=%23ff0000` |

组合示例：`http://127.0.0.1:8765/?state=<STATE>&limit=100&bin=10`

### 健康检查（排障用，务必带 `--noproxy`）
```bash
curl -s --noproxy "*" http://127.0.0.1:8765/api/health            # {"status":"ok"}
curl -s --noproxy "*" http://127.0.0.1:8765/api/summary           # 数据集规模指纹已脱敏
curl -s --noproxy "*" "http://127.0.0.1:8765/api/records?limit=1"
curl -s --noproxy "*" http://127.0.0.1:8765/api/contracts         # changelog 版本 / 常量版本
```

### 技术团队需要知道的边界（都没变）
1. **只读**：页面无任何注入/执行/控制按钮，仅刷新与 URL 筛选
2. **展示纪律照旧**：状态标签原始字面量透传、ns 必带单位假设标注、证据等级不升格、缺数据写「未知」、演示必带横幅
3. **接口未动**：`/api/*` 七个接口签名与返回结构无任何变化，技术团队交付新契约后看板照常经 `sync.py` 适配
4. **新结果类产物**（计数/直方图/分析结论）出现时，通知前端评估是否增加展示即可

### 已知注意事项
- 服务若被回收，用 `start.cmd` 或 Windows 计划任务常驻（不要用 `Start-Process`，代理变量大小写重复会报错）
- `index2.html` 与 `app2.py` 已删除/确认以 `app.py`+`index.html` 为准，勿再引用
- 本机代理坑：curl 必须带 `--noproxy "*"`，否则 502
